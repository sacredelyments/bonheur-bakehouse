# Bonheur Bakehouse

A warm, image-led website for Bonheur Bakehouse, an artisan patisserie in Bangalore.

## Local development

```bash
pnpm install
PORT=5173 BASE_PATH=/ pnpm run dev
```

The site includes the Bonheur Bakehouse story, Sushmita’s chef profile, a complete menu, gateaux pricing by weight, and cake enquiry actions.
